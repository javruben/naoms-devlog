Dispatch · Week 19: The First Merge That Deletes

Three promises to the infrastructure and one to you. An AI can now sit in a human chat channel only with everyone's consent, on a scope you granted and can audit. Releases stopped riding ssh and started fanning out over the peer-to-peer transport the rest of the system already uses. The repository got its first-ever merge that removes weight instead of adding it — a 2.15-gigabyte space floor. And the merge gate kept being rebuilt to tell the truth under load.

Process Dispatch free August 8, 2026·7 min read·meta
TL;DR Week 19 was about weight and trust. An AI can now join a human chat channel only with consent from the people in it, limited to the exact tools you granted, with a participation history any normal user can read — sovereignty over the agent in the room. Release delivery moved off ssh and onto the same peer-to-peer transport the product already runs on. And for the first time ever, a merge removed weight from the repository instead of adding it: 57 oversized evidence files, about 2.15 gigabytes, evicted behind a permanent test — a space floor, with every file still recoverable from history. Under all of it, the merge gate kept being rebuilt to stop mistaking a broken test machine for broken code.

Most weeks here add things. This one is unusual because its centerpiece subtracts — the first merge in the project's history that deletes weight from the repository rather than piling more on. Around that sit three more landings that share a shape: each takes something the system was doing the heavy, old-fashioned way and moves it onto the honest, self-contained path the rest of the product already lives on. And one of them is a feature you'll actually touch — letting an AI into a conversation without letting it quietly become a member.

By the numbers

  • ~702 commits in the window 08-03 → 08-08 (227 merge, ~475 non-merge). A calmer week than the last by volume, and a heavier one by consequence — three of the landings below change how the whole system ships, stores, and governs itself. Churn measures none of that.
  • The number to hold onto is 2.15 gigabytes, removed from the repository in a single merge, behind a test that refuses to let it creep back. It's the first merge that ever made the repo smaller.
  • Fleet-shape caveat, unchanged: ~a hundred concurrent agent worktrees, one merge commit each. A merge count is topology, not features.

Sovereignty over the agent in the room

The user-facing headline, and the one most in keeping with what this project is for. You can now bring an AI into a human chat channel — but only on terms everyone in the room, and you in particular, actually set.

The pieces that make that real: the chooser lists only agents you've actually delegated to; a refused invite tells you the real reason rather than a generic error; admitting an agent is a personal-sovereignty decision that no channel's governance model can override; the tools it gets are exactly the ones consented at approval, minted into a real capability token and checked on every single call at execution time; a cross-person agent has to ask for information rather than silently see it; and the whole participation history — who granted, who objected, what the agent did — is a read-only panel a normal user can open. A joined agent is visible and revocable from the shipping interface. This landed celebrated (close-gate signed, 2026-08-04). The through-line: an agent is a guest with papers, not a fixture that quietly acquires the run of the house.

Releases stopped riding ssh

The first of the three "move it onto the honest path" landings. Shipping a release to the fleet used to fan out over ssh — a separate, host-by-host channel sitting beside the peer-to-peer transport the product already uses for everything else. That's now gone: release dispatch fans out over the same content-addressed peer-to-peer transport the rest of the system runs on, never ssh. It's a wholeness move in the truest sense — one fewer parallel mechanism to trust, one fewer place the system depended on something outside itself to function. Two stale tests that pinned the old ssh-era staging were removed alongside it, because their premise no longer existed.

The first merge that deletes

The centerpiece. Over months, the roadmap accumulated large evidence artifacts — recordings, dumps, fixtures — checked into the repository as tracked files. They were history, and history here is sacred, but they were also dead weight every clone had to carry. This week, for the first time, a merge landed that removed weight: 57 oversized evidence blobs, about 2.15 gigabytes, evicted from the tracked tree — with the count of tracked files five megabytes and larger dropping from eighteen to three — behind a permanent test that fails if an oversized blob is ever committed again. A space floor, not a one-time sweep.

The honesty details are the whole point. Every evicted file is still retrievable from history — the objects stay in the store, reachable from any commit before the eviction; nothing was destroyed, only un-tracked from the working tree. The same landing carried two pre-commit gates and a fix to a merge-gate flaw that had been losing audit evidence, plus an exemption so the two legitimate evidence trees don't trip the new floor. The residual risk was written down, not papered over: a test that constructs one of these paths at runtime would still find it gone. We'd rather ship the floor and name the crack than pretend the floor is a ceiling.

The merge gate, still telling the truth under load

The rebuild that opened last week kept going, and the fixes keep circling one idea: the machine that judges everyone else's work has to be the most honest thing in the building. This week it learned to read its own policy from the target branch rather than from the candidate being judged — so a change can't smuggle in a more permissive rule about how it should be judged. It learned to run many candidates' pipelines in parallel but land them strictly one at a time, so speed never costs a corrupted main line. It stopped letting a merge conflict count as a verdict — an agent three-way-merges inside the pipeline instead. And it started saying, in the config itself, the plain fact that no change is approved by any human or machine — the gate stands on evidence, not sign-off. There was also an operational scare worth admitting: for a stretch the gate was down, on purpose, while a blocker was diagnosed, and the runbook to bring it back was written before it was restarted. Infrastructure that hides its own outages is how small failures become silent ones; this one was loud by design.

A companion thread began teaching that infrastructure to heal itself — wiring the signal that a build host's disk is filling up to an agent that can actually act on it, and separating "the data disk is full" from "the root disk is full" because they're different emergencies. It's early, and it's the right direction: a factory that can notice it's about to jam.

The surface didn't stop either

Under all the plumbing, the things you look at kept getting fixed. A run of owner-reported canvas-window bugs closed — a stacked window now maximizes to a flush layout instead of zooming the whole deck, the first AI chat opens docked rather than floating, search boxes grow without jumping, no stray text gets selected mid-resize, and a broken create-channel dialog layout was repaired. Unglamorous, exactly-right polish on the parts your hands touch every day.

The honest ledger

Told straight, by status:

  • Shipped and celebrated (close-gate signed): consent-governed AI participation in human chat channels, with granted-tool scope, per-call enforcement, and a readable audit trail.
  • Landed on main (owner-approved merges): release dispatch over the peer-to-peer transport instead of ssh; the 2.15-gigabyte repository space floor with its permanent test and two pre-commit gates; a batch of canvas-window bug fixes.
  • Live on main, honestly in-progress: the merge-gate rebuild (policy-from- target, parallel-pipelines-serial-land, and a long tail of honesty fixes, still ongoing as we publish); the infrastructure self-heal wiring; chat-protocol parity for bridged conversations.

We mark these on purpose. Celebrate what's real; never imply the partial is finished.

From the workshop

Why Deleting Was the Headline

It's strange to lead a dispatch with a subtraction. But the eviction is the clearest thing we shipped, because it's the whole philosophy compressed into one merge: history is sacred, so nothing was destroyed — every file is still recoverable; weight is a cost, so the tracked tree got lighter; and creep is the real enemy, so the floor is enforced by a test, not by good intentions. The same three commitments run through the rest of the week. Releases moved onto the transport the system already trusts, so there's one fewer outside thing to depend on. An agent joins a channel on a scope you can audit, so nothing accrues quietly. Add capability by all means — but the mark of a system growing up is that it finally knows how to weigh less, depend on less, and hide less.
